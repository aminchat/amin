# فیلترهای پیشرفته دیده‌بان بازار TSETMC

فیلترهای سطر‌به‌سطر برای صفحه‌ی **«دیده‌بان بازار پیشرفته»** تِست‌م‌سی‌سی:

https://old.tsetmc.com/Loader.aspx?ParTree=15131F#

این پروژه یک **بوکمارکلت** است که بدون هیچ افزونه‌ای، یک پنل کوچک فیلتر روی صفحه باز می‌کند و فیلترها را با استفاده از **موتور داخلی خودِ سایت** (اوبژه‌ی `mw`) اعمال می‌کند.

## چرا این روش؟

کد صفحه‌ی دیده‌بان بازار به‌دقت خوانده شده. یافته‌های کلیدی:

- جدول نمادها یک `<table>` استاتیک **نیست**؛ سلول‌ها `div`هایی هستند که توسط موتور جاوااسکریپتِ صفحه (`MarketWatchPlus` / `mw`) در `#main` رندر می‌شوند.
- سایت **خودش یک سیستم فیلتر** دارد: `mw.FilterCode` یک عبارت جوااسکریپت بولی است که برای هر نماد (`row`) در حلقه‌ی `RenderData` با `eval` اجرا می‌شود؛ نمادی که عبارت‌ش falsy بدهد از DOM حذف می‌شود و بالعکس.
- فیلترها از طریق `mw.SelectFilter(n)` اعمال و با `mw.SaveParams()` در `localStorage` خود سایت (`MarketWatchSettings`) ذخیره می‌شوند.

بنابراین این بوکمارکلت به‌جای دست‌کاری DOM (که با هر بروزرسانی/قالب/مرتب‌سازی از آب در می‌رود)، عبارت فیلتر را **دقیقاً از مسیر رسمی خود سایت** تزریق می‌کند؛ نتیجه:

- فیلترها با هر تیک ۱ ثانیه‌ای داده به‌صورت **زنده** اعمال می‌شوند
- روی **هر قالب نمایش** (جدول کلاسیک، ساده، شخصی و…) کار می‌کنند
- بعد از رفرش صفحه هم **فعال می‌مانند** (چون در تنظیمات خود سایت ذخیره شده‌اند)
- در پنجره‌ی «فیلتر» خود سایت هم به‌عنوان فیلتری با نام «فیلترهای بوکمارکلت» دیده می‌شوند

## نصب (۳۰ ثانیه)

1. در مرورگر یک بوکمارک جدید بساز (مثلاً نوار ستاره‌های بالای صفحه → «ذخیره» )
2. نامش را بگذار: `⚙ فیلتر TSETMC`
3. آدرس (URL) بوکمارک را با کد زیر عوض کن:

```
javascript:(function(){if(window.__tfbLoading)return;window.__tfbLoading=1;var s=document.createElement('script');s.src='https://raw.githubusercontent.com/aminchat/amin/arena/01a04e69-amin/tsetmc-filters/tsetmc-filters.js';s.onerror=function(){var d=document.createElement('div');d.style.cssText='position:fixed;bottom:10px;right:12px;z-index:99999;background:#ffdddd;border:1px solid #999;padding:10px;font-family:Tahoma;font-size:12px;direction:rtl';d.textContent='دانلود کد فیلترها شکست خورد — اینترنت را چک کنید';document.body.appendChild(d);setTimeout(function(){d.remove()},8000)};document.head.appendChild(s);})()
```

4. بوکمارک را ذخیره کن، صفحه‌ی دیده‌بان بازار را باز کن و روی بوکمارک کلیک کن.

> اگر پنل دو بار کلیک کردی، پنل جمع/باز می‌شود (نه اینکه دوباره اجرا شود).

## فیلترهای موجود

| فیلتر | توضیح | مقدار پیش‌فرض |
|---|---|---|
| حذف نمادهای بی‌معامله | `tno > 0` | خاموش |
| حداقل قیمت | آخرین قیمت ≥ X تومان | 5000 |
| حداقل درصد تغییر | درصد آخرین قیمت ≥ X٪ | 1 |
| حداقل حجم معامله | حجم ≥ X سهم | 1000000 |
| حداقل نسبت حجم به حجم مبنا | نمادهای داغ: حجم ≥ X × حجم مبنا | 2 |
| حداقل ارزش معامله | ارزش ≥ X تومان (1000000000 = یک میلیارد) | 1000000000 |
| حذف اوراق و مشتقات | صندوق، اوراق، آتی، حق تقدم، اختیار فروش، کالا و… | خاموش |
| حذف تسهیلات مسکن | نمادهای «تسه…» و «تملي…» | خاموش |
| حذف بازار انرژی | نمادهای flow=6 | خاموش |
| حداکثر P/E | حذف نمادهای P/E بالاتر از X (بدون P/E نمایش داده می‌شود) | 15 |
| جستجوی نماد | فقط نمادهای حاوی رشته‌ی واردشده | — |
| سیاهه | لیست نمادهای همیشگیِ مخفی (با ویرگول جدا کنید) | — |

پنل: گوشه‌ی بالا-راست، قابل جابه‌جایی (با کشیدن سربرگ) و قابل جمع‌شدن (کلیک روی عنوان). شمارنده‌ی «نمایش: X از Y نماد» بالای پنل زنده است؛ اگر فیلتر فعال باشد ولی هیچ ردیفی نماند، هشدار می‌دهد.

## اگر چیزی اعمال نشد (خطا چیه؟)

- **قبل از اعمال** هر تغییری، عبارت ترکیبی روی **تمام** نمادهای موجود اعتبارسنجی می‌شود (دقیقاً مثل دکمه‌ی «اعتبار سنجی» خود سایت، ولی سخت‌گیرانه‌تر). اگر خطا باشد، اعمال نمی‌شود و متن خطا در کادر پایین پنل نمایش داده می‌شود.
- اگر پنل اصلاً باز نشد، یک بنر پایین صفحه می‌گوید `mw پیدا نشد` — یعنی صفحه درست نیست؛ بوکمارکلت فقط روی `ParTree=15131F` (دیده‌بان بازار پیشرفته) کار می‌کند.
- اگر دانلود کد از گیت‌هاب شکست بخورد، بنر قرمز «دانلود کد فیلترها شکست خورد» می‌آید.

## فیلتر سفارشی (بدون پنل)

سایت خودش پنجره‌ی فیلتر دارد (آیکون فیلتر در نوار ابزار دیده‌بان). هر فیلتری می‌تواند از این فیلدها استفاده کند:

| کد | معنا | کد | معنا |
|---|---|---|---|
| `l18` | نماد | `pl` | آخرین قیمت |
| `l30` | نام شرکت | `plc` / `plp` | تغییر / درصد آخرین قیمت |
| `tno` | تعداد معاملات | `pc` / `pcc` / `pcp` | پایانی / تغییر / درصد پایانی |
| `tvol` | حجم معامله | `py` | قیمت دیروز |
| `tval` | ارزش معامله | `pf` / `pmin` / `pmax` | اولین / کمترین / بیشترین |
| `eps` / `pe` | EPS / P-E | `pd1..po5` | سطوح خرید/فروش |
| `bvol` | حجم مبنا | `z` | درصد شناوری |
| `tmax` / `tmin` | سقف / کف روز | `cs` | کد گروه |

علاوه بر این در دامنه‌ی اجرای فیلتر، متغیرهای `row` (تمام فیلدهای بالا)، `flow` (بازار: 1/3 بورس، 2 فرابورس…)، `yval` (نوع ابزار) و `cgrvalcot` هم در دسترس‌اند. مثال:

```js
row.pl >= 5000 && row.tvol >= 2*row.bvol && yval=="300"
```

> نکته: فیلترهای این بوکمارکلت همان مکانیزم را استفاده می‌کنند؛ اگر بخواهید فیلتر دستی بنویسید، مستقیم در پنجره‌ی فیلتر سایت واردش کنید (با فرمت `(pl) >= 5000` که خود سایت آن را تبدیل می‌کند).

## ساختار پروژه

```
tsetmc-filters/
├── tsetmc-filters.js      ← کد اصلی که بوکمارکلت آن را دانلود و اجرا می‌کند
├── README.md
└── test/
    ├── harness.js         ← تست یکپارچه با jsdom
    ├── fixtures/          ← کدهای واقعی موتور سایت (استخراج‌شده از صفحه) برای تست
    │   ├── engine_marketwatch.js
    │   ├── helpers.js
    │   └── sectors.js
    └── package.json
```

## اجرای تست‌ها

تست یکپارچه، **همان موتور واقعی سایت** (`MarketWatchPlus` از کد صفحه) را در jsdom بالا می‌آورد، داده‌ی نمونه می‌زند و اسکریپت بوکمارکلت را روی همان مسیر `eval(mw.FilterCode)` و `RenderData` واقعی اجرا می‌کند:

```bash
cd test
npm install
node harness.js
```

نتیجه‌ی فعلی: **32/32 موفق** (اعمال/لغو فیلترها، ترکیب چند فیلتر، جستجو، سیاهه، اعتبارسنجی خطا، پایداری localStorage، اجرای دوباره).

## محدودیت‌ها و نکات

- کد از گیت‌هاب با `raw.githubusercontent.com` دانلود می‌شود (CORS ندارد، چون از تگ `<script>` استفاده می‌شود). اگر روزی گیت‌هاب مسدود شود، کافی است `tsetmc-filters.js` را در هر میزبانی ثابت بگذاری و فقط آدرس `s.src` داخل بوکمارکلت را عوض کنی.
- نام شاخه‌ی گیت‌هاب در آدرس بوکمارکلت مهم است؛ اگر فایل به شاخه‌ای دیگر جابه‌جا شد، آدرس را به‌روزرسانی کن.
- فیلترها فقط نمایش (نمایش/عدم نمایش سطر) را کنترل می‌کنند و روی داده‌ی خام سایت اثری ندارند.
- این پروژه غیررسمی است و وابسته به سایت TSETMC نیست.
