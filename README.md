# مدیریت سرمایه

برنامه وب فارسی برای بودجه و خرج شخصی به روش چهار پاکت. نسخه `1.1.0`.

PWA است؛ بدون بک‌اند. داده در `localStorage` می‌ماند و در صورت ورود گوگل با فایل `capital-app-data.json` روی Drive همگام می‌شود.

## لینک اجرا

- پیش‌نمایش این شاخه: [https://aminchat.github.io/amin/](https://aminchat.github.io/amin/)

## اجرا

فایل‌ها استاتیک‌اند. از ریشه پروژه یک سرور محلی بالا بیاور (ماژول‌های ES روی `file://` کار نمی‌کنند):

```bash
python3 -m http.server 8080
```

سپس `http://localhost:8080` را باز کن.

## ساختار

| مسیر | نقش |
| --- | --- |
| `index.html` | پوسته UI |
| `css/app.css` | استایل |
| `js/app.js` | راه‌اندازی، ناوبری |
| `js/state.js` | مدل داده و محاسبات |
| `js/forms.js` | فرم تراکنش، حساب، انتقال، دارایی |
| `js/render.js` | رسم تب‌ها |
| `js/sync.js` | ورود گوگل و همگام‌سازی Drive |
| `js/jalali.js` | تاریخ شمسی |
| `sw.js` | کش آفلاین فقط برای فایل‌های همین مبدأ |

## اصلاح‌های ۱.۱.۰

- قیمت امروز دارایی دیگر با واحد پول تداخل ندارد
- همگام‌سازی Drive بر اساس `updatedAt` است و روی ذخیرهٔ در صف overwrite نمی‌کند
- توکن گوگل بعد از انقضا callback درست را صدا می‌زند
- مبلغ تراکنش به واحد همان حساب است
- ویرایش و حذف انتقال هر دو طرف جفت را با هم عوض می‌کند
