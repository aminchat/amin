# مدیریت سرمایه — برنامهٔ مالی شخصی (PWA)

[English](./README.md) · نسخهٔ اصلی: <https://aminchat.github.io/amin/> · نسخهٔ آزمایشی: <https://aminchat.github.io/amin/test/>

«مدیریت سرمایه» یک برنامهٔ وب نصب‌شدنی و آفلاین برای بودجه‌بندی شخصی است. بدون سرور، بدون ثبت‌نام و بدون ردیابی: داده‌ها روی گوشی خودت می‌مانند (در صورت تمایل با رمزنگاری سرتاسری) و می‌توانند از طریق گوگل‌درایوِ خودت بین دستگاه‌ها همگام شوند.

منطق برنامه بر پایهٔ **روش پاکت‌ها** است: بودجهٔ هر ماه بین چند پاکت تقسیم می‌شود و برنامه در یک نگاه می‌گوید هنوز طبق برنامه پیش می‌روی یا نه.

---

## امکانات

### بودجه و پاکت‌ها
- بودجهٔ ماهانه با انتقال ماندهٔ ماه قبل.
- پنج پاکت خرج با سهم هدف: **ضروریات ۶۰٪**، **سرمایه‌گذاری ۲۰٪**، **تفریح ۱۵٪**، **نیکوکاری ۵٪** و **هدررفت** (هدف صفر — برای صداقت با خودت).
- پاکت جداگانهٔ **قرض / امانت** که *خارج از* خرج و درآمد است؛ قرض دادن یا پس گرفتن پول، تصویر ماه را به‌هم نمی‌زند.
- کارت «قابل خرج» در خانه: چقدر از ماه مانده و تا آخر ماه روزی چقدر می‌توانی خرج کنی.
- چک‌لیست «شروع سریع» برای کاربر تازه (ساخت حساب ← ثبت بودجه ← اولین خرج).

### تراکنش‌ها
- کیبورد عددی سریع برای ثبت خرج با دو ضربه؛ مبلغ با جداکنندهٔ هزارگان و خط «به حروف» («۱٫۵ میلیون تومان»).
- فرم کامل: خرج / درآمد، پاکت، حساب، تاریخ، توضیح.
- **فاکتور**: یک تراکنش با چند قلم (نام، مقدار، واحد، قیمت واحد) و پاکت جداگانه برای هر قلم؛ برنامه چک می‌کند جمع اقلام با مبلغ کل بخواند.
- **انتقال** بین حساب‌ها، از جمله بین دو ارز مختلف با نرخ اختصاصی همان انتقال.
- کشیدن ردیف برای حذف/ویرایش، نگه‌داشتن برای تکرار؛ یادداشت «اگر این خرج را نمی‌کردی چه می‌شد؟» برای هدررفت‌ها.
- **ثبت از عکس** (اختیاری، با کلید Gemini خودت): عکس لیست دست‌نویس یا فاکتور را بده تا تراکنش‌ها/اقلام برای بازبینی پر شوند.
- دفتر هر حساب با ماندهٔ جاری؛ دفتر هر پاکت به تفکیک ماه.

### گزارش
- حکم ماه («طبق برنامه پیش می‌روی»، «کمی از برنامه فاصله داری»، «X از سهمش رد شد») بر اساس فاصلهٔ توزیع خرج واقعی از سهم پاکت‌ها.
- نمودار گلوله‌ای برای هر پاکت: نوار کم‌رنگ = سهم از بودجه، نوار پررنگ = خرج واقعی، بخش قرمز = عبور از خط هدف.
- اقساط پرداخت‌شدهٔ ماه و گردش قرض/امانت جداگانه نمایش داده می‌شوند.

### دارایی
- **حساب‌ها**: کارت بانکی، نقد، ارز دیجیتال، کیف پول آنلاین؛ گروه‌بندی بر اساس مؤسسه؛ چندارزی با نرخ برای هر ارز؛ موجودی اولیه؛ ۴ رقم آخر کارت.
- **سرمایه**: طلا، ملک، ماشین، رمزارز یا هر چیزی با مقدار، قیمت خرید و قیمت روز؛ سود/زیان کلی و برای هر دارایی.
- **طلب و بدهی**: پولی که داده‌ای یا گرفته‌ای، با سررسید، پرداخت‌های جزئی (هر پرداخت یک تراکنش مستقل)، تسویه به هر حسابی، یادآوری برای موارد نزدیک یا عقب‌افتاده.
- **اقساط**: وام بانکی (اقساط مساوی یا اصل ماهانه + سود دوره‌ای) و خرید قسطی (پیش‌پرداخت + n × قسط در مقایسه با قیمت نقدی). جدول قابل ویرایش برای هر ردیف (مبلغ، تاریخ، سود، جریمه)، تیک «پرداخت شد» با یک ضربه که تراکنش واقعی می‌سازد، پیگیری عقب‌افتاده‌ها، گزارش سود، واریز اختیاری اصل وام به حساب.
- نمای کلی خالص دارایی (نقد + سرمایه) و تعهدات (بدهی‌های باز + اقساط پرداخت‌نشده).

### واحد پول
- هر واحد پایه‌ای (پیش‌فرض تومان)؛ حدود ۲۵ ارز آماده به‌علاوهٔ ارز دلخواه.
- اعداد کوتاه روی کارت‌های خلاصه (۲٫۴ میلیون / ۸۵۰ هزار) با گردکردن درست؛ اعداد کامل داخل تراکنش‌ها.
- واحد پایه بعداً قابل تغییر است؛ بودجه‌ها و نرخ‌ها تبدیل می‌شوند.

### زبان و تقویم
- **فارسی (راست‌به‌چپ) و انگلیسی (چپ‌به‌راست)**؛ خودکار از زبان گوشی یا دستی در تنظیمات.
- ارقام فارسی یا لاتین، واحدهای بومی (میلیون/هزار یا million/thousand)، و CSS منطقی تا کل چیدمان درست آینه شود.
- تقویم **شمسی یا میلادی** برای نمایش؛ ماه‌های بودجه همیشه بر اساس ماه شمسی‌اند و در حالت میلادی به‌صورت بازهٔ تاریخ نشان داده می‌شوند.

### امنیت و حریم خصوصی
- **رمزنگاری سرتاسری** اختیاری (AES-256-GCM با کلید مشتق از PBKDF2). کلید داده با رمز عبور و با **عبارت بازیابی ۱۲ کلمه‌ای** پیچیده می‌شود؛ بدون یکی از این دو هیچ‌کس — حتی گوگل — نمی‌تواند فایل را بخواند.
- **ورود با اثر انگشت / چهره** (WebAuthn) به‌عنوان میان‌بر روی رمز عبور.
- تغییر رمز و «یکی‌کردن دستگاه‌ها» وقتی چند دستگاه رمز متفاوت دارند.
- دکمهٔ «مخفی‌کردن اعداد» برای استفاده در جمع.
- **پشتیبان‌گیری**: خروجی کل داده به JSON و بازیابی بعدی (تنظیمات ← پشتیبان‌گیری).
- [سیاست حریم خصوصی](./privacy-fa.html) · [شرایط استفاده](./terms-fa.html) (از تنظیمات ← دربارهٔ برنامه هم در دسترس است).

### همگام‌سازی و آفلاین
- PWA نصب‌شدنی با سرویس‌ورکر؛ کاملاً آفلاین کار می‌کند.
- **همگام‌سازی گوگل‌درایو** اختیاری (`appDataFolder`، فایل `capital-app-data.json`): آخرین تغییر بر اساس `updatedAt` برنده است؛ اگر رمزنگاری روشن باشد فایل رمزشده می‌رود.
- یادآوری بومی (Notifications) برای طلب/بدهی و اقساط نزدیک سررسید.

### ظاهر
- پنج تم: روشن (پیش‌فرض)، شب، اقیانوس، جنگل، غروب.
- چیدمان فشرده و مناسب انگشت شست؛ کارت‌های حساب، بدهی و اقساط از یک کامپوننت مشترک استفاده می‌کنند.

## اجرای محلی

همه‌چیز استاتیک است. ماژول‌های ES روی `file://` بارگذاری نمی‌شوند، پس پوشه را سرو کن:

```bash
python3 -m http.server 8080
# سپس http://localhost:8080
```

پوشهٔ `test/` نسخهٔ مستقلی است برای آزمایش تغییرات قبل از انتقال به ریشه (کلیدهای ذخیره‌سازی و نام فایل درایو متفاوت، بدون سرویس‌ورکر).

## ساختار پروژه

| مسیر | نقش |
| --- | --- |
| `index.html`، `css/app.css` | پوسته و استایل |

| `js/i18n.js`، `i18n/*.js` | لایهٔ ترجمه؛ دیکشنری‌های `fa` / `en` |
| `js/state.js` | مدل داده، محاسبات، ارزها |
| `js/render.js` | نمای خانه، تراکنش‌ها، گزارش، دارایی |
| `js/forms.js` | فرم تراکنش / فاکتور / انتقال / حساب / دارایی / بودجه |
| `js/debts.js`، `js/installments.js` | طلب و بدهی، اقساط |
| `js/prefs.js` | تنظیمات، ویزارد امنیت، تم‌ها، نرخ‌ها |
| `js/crypto.js`، `js/securestore.js` | رمزنگاری و مدیریت کلید |
| `js/sync.js` | ورود گوگل و همگام‌سازی درایو |
| `js/scan.js` | ثبت از عکس با Gemini |
| `js/jalali.js` | تبدیل شمسی ↔ میلادی و قالب‌بندی تاریخ |
| `js/utils.js` | قالب‌بندی اعداد، ورودی مبلغ، ذخیره‌سازی |
| `sw.js`، `manifest.webmanifest` | کش آفلاین و اطلاعات نصب |

## مدل داده (خلاصه)

- `transactions[]` — `{id,type:'out'|'in'|'transferOut'|'transferIn',cat,amount,accountId,dateISO,note,lines?,debtId?,planId?}`
- `accounts[]`، `investments[]`، `budgets{ 'yyyy/mm': {amount} }`، `rates{ cur: rate }`
- `debts[]` — `{…, payments:[{id,amount,dateISO,accountId,txId}]}`
- `installments[]` — `{kind:'loan'|'purchase', mode, rows:[{dueISO,amount,interest,penalty,paidISO,txId}]}`

همهٔ مبالغ به واحد خودِ حساب ذخیره می‌شوند؛ واحد پایه فقط برای جمع‌ها به کار می‌رود.

## نسخه

فعلی: `2.11.0` (ریشه) / `2.11.0-test` (آزمایشی). رشتهٔ نسخه در `js/utils.js` (`APP_VERSION`) است و در تنظیمات ← دربارهٔ برنامه نمایش داده می‌شود.
